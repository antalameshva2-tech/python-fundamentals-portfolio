# 🌟 Interactive Personal Data Collector

## 📌 About the Project

The Interactive Personal Data Collector is a simple Python program
that collects personal information from the user and displays
useful information about the entered data.

## 🎯 Objective

This project is created to practice the fundamental concepts of Python
such as input, output, variables, data types, operators, type casting,
`type()` and `id()` functions.

## ✨ Features

- 👤 Collects user's name
- 🎂 Collects user's age
- 📏 Collects user's height
- 🔢 Collects favourite number
- 📅 Calculates approximate birth year
- 🔍 Displays data type of each variable
- 💾 Displays memory address using `id()`
- 🔄 Demonstrates type casting
- ➕ Performs basic calculations

## 🐍 Python Concepts Used

- `print()`
- `input()`
- Variables
- String
- Integer
- Float
- `type()`
- `id()`
- Type Casting
- Arithmetic Operators
